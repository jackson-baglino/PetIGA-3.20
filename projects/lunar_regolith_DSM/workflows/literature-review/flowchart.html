Workflow design

literature-review

A reusable literature-review workflow built around a library with branches (numerical methods, sublimation physics, sintering, planetary setting, properties), each seeded with papers the user chooses. Seeds steer discovery (citation chaining), screening (a scripted baseline ranks candidates by similarity to the seeds) and calibration. Scripts search Crossref, OpenAlex, Semantic Scholar and arXiv and resolve every candidate; two Haiku screeners judge abstracts, combined by a fixed rule (any include is kept) and measured against the baseline; an on-demand scout challenges novelty claims and memo gaps using search terms the user approves.

Papers are prepared from the best source (LaTeX or XML before Marker), with 300 dpi tiles, structured tables and a full-text passage index searched by keyword and by meaning. A Sonnet reader extracts claims and symbols; scripts check quotes, table cells and units (dimensional analysis); an Opus checker confirms each claim from page images, and its own corrections are checked again; the checker transcribes values blind first; a fresh Sonnet call and a math OCR model read the values memos rely on blind. The user reads core papers and audits the claims memos rely on plus 60 random others. A script is the only library writer. Agents write nothing and hold permissions written in enforced settings files, checked by script; whenever it works with library files, the main session runs in a review mode with no way out and reads only an allow-list; the sandbox fails closed; a content-addressed archive in the course folder keeps everything a recheck needs. Papers go to the user's Zotero, and papers the user saves there come back in.

P1 prepare.pyscript——Takes text from the best source (LaTeX, XML, then Marker), renders pages and 300 dpi tiles, extracts tables twice and crops figures.

Y1 beth-synthesizer (on request at U4, or at close)agentclaude-opus-5-5—Writes one memo per question from every verified claim for it, by fixed query, citing claim versions; splits large sets.
Y2 check_citations.pyscript——Checks each memo sentence cites a verified claim, and each tagged number matches that claim's value, unit and quantity.
Y3 beth-memo-checker (+ beth-skeptic, model-critical)agentclaude-opus-5-5—Call 1 judges support on the cited claims only; call 2 lists omitted or contradicting claims and passages.

R1 morty-reader (task: retag; when a question is added or changed)agentclaude-sonnet-5-5ReadFor a new or changed question: a passage search finds pages, the reader proposes questions[] additions, beth-checker confirms.
SC0 screen_baseline.py (tier M, L)script——Excludes by fixed rules (document type, years, language) and ranks the rest by similarity to seed abstracts: the screening baseline.
P2 build_index.pyscript——Cuts text into structural chunks (paragraph, equation, table, caption), embeds them with a pinned local model and builds a keyword index.
E3b check_units.pyscript——Parses every unit with Pint, compares dimensions with the verified units table, and checks each equation term by term with SymPy.
X1 morty-blind-reader + ocr_math.pyagentclaude-sonnet-5-5; math OCR modelRead (tiles only)Given a tile and a quantity name, never the value, each transcribes it; a script compares reader, blind checker, blind reader and OCR.
Z1 zotero_add.pyscript——Adds each acquired paper with its PDF to the user's Zotero collection for its branch; never duplicates or edits an item.
