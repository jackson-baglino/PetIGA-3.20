literature-review

A reusable literature-review workflow for reviews of any size. The user writes a brief (questions, criteria, tier); scripts search Crossref, OpenAlex, Semantic Scholar and arXiv, follow citations, and resolve every candidate so no invented reference survives; two Haiku screeners judge each abstract independently and an Opus checker settles disagreements. Scripts fetch open-access PDFs (Literature/, OpenAlex, arXiv, repositories) and check each is the paper asked for; a preprint or repository copy is compared with the published record; the user supplies any paper not found.

A fresh Sonnet reader per paper extracts claims with verbatim quotes, pages and equations from page images and Marker text; core papers are read twice independently. A script checks every quote and equation against the page; an Opus checker, blind to the reader's reasoning, judges every claim on the page image. A script (the curator) is the only writer to the library and refuses anything unchecked; nothing is ever deleted. Memos cite claim IDs only, are checked by script and by a Fable checker, a tag report after each wave proposes merges and new tags, and the user decides whether to close, expand or retract the review and which tag changes to accept. A calibration run with planted errors gates the first real wave.

Draft design for review, 2026-10-23, revision 2 (user decisions applied). Nothing built. Details and open decisions: WORKFLOW.md.
