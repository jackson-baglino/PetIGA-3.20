Workflow design

model-development

The model line derives, discretizes and implements a model of ice, water vapor and heat in a regolith pore space, then writes a teaching document. The script run_md.py owns the loop and the state (runs.db and files); every agent call gets a fresh context and one work order, and all four agents run claude-opus-5-5.

Each stage's output is checked by something other than its producer: the verifier writes the checks for M1, M3 and M4 and the tests in M5, library_search.py checks every quoted citation, and mutate.py plants bugs to measure the tests. A Stop hook runs each stage's structural pre-check and every call must return schema output, or it is retried once.

Solver runs go only through run_test.sh with caps: at most 8 ranks, 20k to 100k DOFs per rank, a 30 minute timeout, and the locked test list only; in M6 a failing test gets at most 3 fix rounds before the foreman triages it. The user decides at six blocking gates (scope, selection, derivation, discretization, test lock, write-up); the doc 18 comparison and the M8 settings are non-blocking review items; a mutation miss reopens the test lock.
