units-verification

Checks every row of memory/semantic/units.md (62 symbols from Kaempfer & Plapp 2009 and Moure & Fu 2024 with its SI) against images of the cited pages. A Sonnet agent reads each page blind, without seeing the table's answer; a script compares its reading with the table; an Opus agent judges only the rows that disagree; the user inspects every disputed row and a random sample of agreed ones.

The pipeline is first run on eight rows with planted errors, and the real run starts only if it catches them. Agents see page images only, never the PDF text layer, which drops exponents and minus signs.

Design for review, 2026-10-22. Nothing is built yet. Details: WORKFLOW.md.
