Workflow design

units-verification

Checks every row of memory/semantic/units.md (58 symbols from Kaempfer & Plapp 2009 and Moure & Fu 2024 with its SI) against images of the cited pages: unit, printed symbol, meaning, page and printed value. Marker (a local OCR model) and a Sonnet agent each read the pages independently, the agent without seeing the table's answer; a script compares both readings with the table; an Opus agent judges the rows that disagree and reviews every row's meaning. Agents run headless in a clean folder holding only page images, and a script audits each transcript.

The pipeline is first run on ten rows with planted errors and four untouched controls, and the real run starts only if it catches them. The user inspects every row the Opus agent flagged plus a random 10 % of the agreed rows. Page images and Marker text are not committed; they are reproducible from the DOIs and PDF hashes in the manifest.

Stages 1 and 2 built; agents awaiting approval; real run, U1 and S5 not yet. 2026-10-22. Details: WORKFLOW.md.
