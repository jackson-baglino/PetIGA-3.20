# Prescribed contact angle in a WEDGE, for scripts/HPC/submit_batch.sh --tests-file
#
# Two runs, the same tapered domain as the 2026-08-07 wedge_bc campaign, now
# with the wall free-energy term enforcing 60 and 120 degrees at both regolith
# walls. The wedge_band IC starts at 90 degrees (an apex-centred annulus is
# perpendicular to both walls), so each run relaxes 90 -> its prescribed angle.
#
# What is new physically: in the flat channel theta sets the meniscus curvature
# outright, R = H/(2|cos theta|), and nothing else varies. Here the channel
# WIDTH varies along x, so the same theta gives a curvature that changes with
# position -- a gradient the ice can migrate along at constant total mass.
# theta < 90 and theta > 90 should drive that migration in opposite directions.
#
# BOTH boundary-condition types, so the BC's effect and the angle's effect can
# be told apart. Same domain, same IC, same t_final; only the BCs differ.
#
#   wedge150_*     sealed: no flux anywhere. Reaches a true steady state, so the
#                  angle comes out essentially exactly Young (+0.004 deg in the
#                  flat channel). Ice can REDISTRIBUTE along the taper at
#                  constant mass but cannot grow or shrink on net.
#
#   wedgeres150_*  reservoirs: T pinned on every face, vapour at saturation on
#                  the x-faces. Identical to the 2026-08-07 wedge_bc campaign's
#                  rhov_eq_eq case, so these are directly comparable to it.
#                  Permits net growth/shrinkage, at the cost of ~1 deg of angle
#                  error because the interface never stops moving.
