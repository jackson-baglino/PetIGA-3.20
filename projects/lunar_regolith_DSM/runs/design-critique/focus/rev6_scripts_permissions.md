1. Deterministic replacements. For every stage run by an agent, ask: could a
   script produce the same output from the same input, or could a script do
   most of it and leave the agent a smaller, checkable decision? Name the
   stage, what the script would do, and what would be lost. Also name any
   check that relies on a model where a formula, a lookup or a comparison of
   two sources would do.
2. Agent count. For each agent, is a separate agent justified by different
   information, different permissions or a needed second opinion? If not,
   say which agent or script should absorb it.
3. Permissions. Where are the permissions in section 4 weaker than stated: a
   rule enforced only by the prompt, a tool or host that is broader than the
   job needs, a path by which untrusted text (a paper, a web page, a
   retrieved passage) could cause an agent or script to act, or a script
   that can write or reach the network more widely than listed?
