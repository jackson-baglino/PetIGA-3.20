- Ch. 4 p.110–117: canonical problem P(λa, λb): T(1) = t·grad T(0) + T̄(1) (Eq. 4.31); "we combine the three solutions into a vector t*": div_y(λ(grad_y t + I)) = 0; [t]_Γ = 0; [λ(grad_y t + I)]_Γ·n = 0; ⟨t⟩ = 0 (Eqs. 4.26–4.30). λeff = (1/|Ω|)[∫Ωa λa(I + ∂t_a/∂y)dΩ + ∫Ωb λb(I + ∂t_b/∂y)dΩ] (Eq. 4.37), symmetric positive (p.118).
- p.112: regimes by contrast L = λb/λa: L = O(1) "without any restriction on connectivity" → classical; L = O(ε) particular case; L = O(ε²) (weak inclusions) → memory effects (transient only); L = O(ε^-1) with highly conductive NON-connected inclusions → classical form but non-standard cell problem (§4.2.4).
- p.110: "In order to apply this technique, we will assume the medium to be periodic."
- Ch. 2 p.~66: "the assumption of periodicity is not an obstacle in estimating the effective properties of a material with a random microstructure"; Ch. 3 p.~74: "Here we justify the use of the method of periodic media for treating real aperiodic materials when there is a separation of scales."
- §3.4.3: actual scale ratio εr must be evaluated from the macroscopic field gradient, not only sample size.
