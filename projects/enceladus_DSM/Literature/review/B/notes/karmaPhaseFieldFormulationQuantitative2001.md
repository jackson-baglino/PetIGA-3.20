# karmaPhaseFieldFormulationQuantitative2001 — Karma (2001), Phys. Rev. Lett. 87(11), 115701

**Summary.** A quantitative phase-field formulation for dilute-alloy solidification. An antitrapping current removes spurious interface effects (solute trapping and others) in the thin-interface limit for one-sided diffusion. Not cited.

**Relevance.** Only background, on the antitrapping current for unequal diffusivities. Our ice–air model has very different diffusivities across the interface (vapour diffuses only in air), so it is the kind of one-sided problem where antitrapping-type corrections matter. That point belongs, if anywhere, with the thin-interface discussion, and K&P 2009 already handles their case. No citation recommended unless the authors discuss one-sided-diffusion corrections.
