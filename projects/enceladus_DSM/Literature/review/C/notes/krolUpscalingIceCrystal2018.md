# krolUpscalingIceCrystal2018 — Krol & Löwe, Acta Mater. 151, 478–487 (2018)
Read (main text).
## Summary
Rigorous upscaling of vapor-diffusion crystal growth to averaged evolution equations for ice volume fraction, interface area per volume (SSA), Gaussian curvature and mean-curvature moments; benchmark vs interface tracking and 4D µCT.

- Not cited. Relevant background for using SSA as a state variable (Section 5, "SSA as the state variable"): SSA evolution follows from interface growth velocities (as in Braun 2024). Optional.
