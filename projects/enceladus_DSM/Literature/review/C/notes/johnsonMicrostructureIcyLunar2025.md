# johnsonMicrostructureIcyLunar2025 — Johnson, Asenath-Smith, Lieblappen, Dreyer et al., J. Phys. Chem. C (2025)
Read (13 pp; ACS text layer garbles operators; numbers not used).
## Summary
µCT of icy lunar regolith simulants prepared four ways (pressure-sintered, wet-mixed, unconsolidated granular, temperature-sintered); sintering theory background; argues dry-mixed and sintered analogs are lunar-relevant, not wet-mixed.
## Findings
- Sintering of icy regolith in the solid phase changes porosity, pore size, ice particle size and ice–regolith connectivity, which drive bulk properties (strength) (p.1–3).
