# ---------------------------------------------------------------------------
# Python 3.11
#
#   Chosen to match the HPC: the Resnick module tree tops out at
#   python/3.11.6, so 3.11 is the newest interpreter available on both the
#   cluster and the Mac. Local dev uses Homebrew python@3.11 (3.11.14) --
#   same minor version, so cp311 wheels are interchangeable.
#
#   Consequence: numpy and scipy are held one minor behind latest. numpy 2.5+
#   and scipy 1.18+ declare requires-python >= 3.12 and CANNOT be installed
#   here. 2.4.6 / 1.17.1 are the newest that still ship cp311 wheels.
#   Everything else below is at its current release.
#
# Recreate this environment from scratch:
#   rm -rf venv_enceladus
#   python3.11 -m venv venv_enceladus
#   venv_enceladus/bin/python -m pip install --upgrade pip setuptools wheel
#   venv_enceladus/bin/pip install -r requirements.txt
#
# Only direct dependencies are pinned; transitive versions are resolved by pip
# and constrained by these pins.
# ---------------------------------------------------------------------------
