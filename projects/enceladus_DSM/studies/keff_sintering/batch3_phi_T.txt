# Batch 3 of the k_eff sintering campaign: the porosity x temperature matrix.
#
# phi {0.275, 0.325, 0.375, 0.425, 0.475} x T {-5, -10, -20, -30, -40} C x
# 5 packings per porosity (inputs/packings/keff_LR40/, one unique seed each,
# built by make_packings.sh with the y-seam gate) = 125 runs, 30 d each,
# alpha_c = 1e-3, dtmax = 1.09*tau_sub per temperature.
#
# Why these: porosities evenly spaced by 0.05 (user, 2026-09-28); 0.475 is kept
# to show where 2D stops being a snow analogue (its solid spans both axes in 1
# of 5 packings). Temperatures bracket the Molaro pair (-5, -20) and extend
# cold. Temperature acts as a pure time rescaling in this model (batch 2,
# CAMPAIGN.md stage 3), so the five temperatures cover a ~60x range of
# t/tau_sub for every porosity and re-test that collapse at each one.
#
# k_eff every 5 steps (studies/keff_sintering/sampling_stride.py: max error
# after 1 d <= 0.3%), except -40 C, which takes only ~100 steps and samples
# every step (per-job third field below). 50 log-spaced snapshots + the 1 s
# opening frame: ~9 GB/run, ~1.1 TB for the batch.
#
# Cost (measured basis: batch 2 at 241 ranks, ~20 s/step + k_eff/5):
#   -5 ~$30, -10 ~$20, -20 ~$9, -30 ~$4, -40 ~$3 per run  ->  ~$1.66k.
#   This batch runs at 60k DoF/core (401 ranks). If steps are not faster
#   there, core-hours rise up to 1.66x: ~$2.75k worst case. Longest run
#   (-5 C) ~10.5 h at 241 ranks: inside the 24 h limit either way.
#
