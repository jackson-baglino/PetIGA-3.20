# 1. DEMMENIE PILOT — production mesh and eps, truncated to 10 min.
#    ~78.3M dof, ~180 steps. Deliberately not a coarse-eps pilot: the
#    kinetic/thermal/vapour split of tau_sub is set by the comp_eps safety
#    factor alone, so a coarser arm would sit in a different physical regime
#    and predict nothing about the production run.
#    GATE: does it stay stable, is the t=0 neck r/R ~ 0.092 (the
#    mesh-convergence extrapolation), and does the early rate match the u^3
#    estimate that sized t_final = 5 h?
sinter_2D_L2196um_eps0.32um_axisym_D1mm_r0p09:sinter_T-3_h1.00_10min_a9.0e-2

#      These are cheap enough to run alongside the gate rather than after it.
#      Expectation, stated up front: none of them recovers 1/3, because this
