#       --tests-file studies/sinter_exponent/batches/alpha_ladder.txt
#
# THE QUESTION
# ------------
# alpha_c decides which transport regime the run is in, through the crossover
# length L* = beta_HK*D_v. Kuczynski's r ~ t^(1/3) is DERIVED for the
# attachment-limited case (r_neck/L* < 1), so if our exponents have been low
# because we were sitting in the diffusion-limited regime, the exponent should
# TURN ON as the ladder descends. If it does not, the low exponent is
# geometric (window width / resolution floor) and alpha_c was never the issue.
#
# Either answer is worth having, and this is by far the cheapest way to get it:
# ~60 ranks on 1.63M nodes per rung, and the step count FALLS going down the
# ladder because tau_sub grows as 1/alpha_c faster than t_final does.
#
#   rung   alpha_c    beta_eff/beta(ice)  r_neck/L*  regime      steps
#   1      1.341e-2        0.727            1.93     mixed        1378
#   2      1.000e-2        0.797            1.44     mixed         638
#   3      5.620e-3        0.886            0.81     attachment    300
#   4      1.000e-3        0.980            0.14     attachment    300
#
# ONE GEOMETRY FOR ALL FOUR. eps = 2.4002e-07 is fixed by the neck-resolution
# floor r/R >= sqrt(12*eps/R), which is alpha_c-INDEPENDENT, so the 2281x713
# mesh is valid at every rung and alpha_c is the only variable. Sealed
# (zero-flux) boundaries throughout for the same reason -- the boundary
# comparison is a separate axis, already covered by the gate batch.
#
# Rung 3 (5.62e-3) is Braun et al.'s series-2 optimum and the closest analogue
# to our case: a single constant alpha, not the two-stage behaviour their
# series 1 shows under a temperature gradient. Our runs are isothermal
# (grad_temp0 = 0), so that two-stage feature should not appear.
#
# Rungs above 1.341e-2 are deliberately absent. At alpha_c = 1e-1, the top of
# Braun's range, Eq. 42a forces ~1300M nodes and beta_eff/beta reaches -1.95 --
# the effective kinetic coefficient changes sign. That part of the range cannot
# be run at any affordable mesh.
#
# ANALYSIS: anchor every rung at Molaro's first measured neck so the clocks are
# comparable, then compare the fitted exponent ACROSS rungs:
#   python postprocess/fit_neck_growth.py <run1>/neck_width.csv ... \
#       inputs/validation/molaro2019_fig11_T-20.csv \
#       --anchor-neck 1.6405e-5 --demmenie
