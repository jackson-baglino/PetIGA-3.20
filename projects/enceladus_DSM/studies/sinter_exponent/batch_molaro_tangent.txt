# Three arms, ~140 core-h each (1.63M nodes, ~1400 steps, ~61 ranks) -- about
# 420 core-h total, so this whole set costs less than 10% of one Demmenie
# production run and needs 2 nodes rather than 31.
#
# WHAT IS DIFFERENT FROM THE r0p22 SET ALREADY RUNNING
# ----------------------------------------------------
# 1. Starts at EXACT TANGENCY (zero sharp-interface neck) instead of at a
#    chosen 39.0 um chord. The initial neck stops being a free parameter.
# 2. eps 3.479e-7 -> 2.4002e-07, which drops the resolution floor from a
#    38.06 um neck width to 31.61 um -- BELOW Molaro's first measured 32.81 um.
#    Without that the clock-shift comparison would anchor inside the region
#    where the fillet is thinner than the interface and the dynamics are wrong.
# 3. t_final 8 h -> 15 h, because from zero the neck needs ~28 ks to reach
#    their last measured point.
# 4. -t_out_log_t0 100 s, so the log schedule spans the 2.7 decades that matter
#    instead of 8.7 decades that mostly predate any resolvable neck.
#
# Together the two sets form a 2 x 3 matrix (initial condition x boundary
# treatment). Anything common to all six is a property of the model, not of
# the setup -- which is the point.
#

# clocks directly (ours starts at contact, theirs at an unknown time after):
