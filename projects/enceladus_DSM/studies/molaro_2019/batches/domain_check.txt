# WHAT THIS DECIDES
# -----------------
# The old Molaro geometry put the Dirichlet wall 20 um from the ice
# (L/a_eff = 1.08). Neck growth is driven by a local curvature-difference
# dipole, whose image correction against a Dirichlet wall scales as (a/L)^3:
#
#   arm    L/a_eff   Lz x Lr [um]    Melem   predicted neck err
#   dom2      2.01     450 x 225      3.03        12.5 %
#   dom3      3.03     680 x 340      6.92         3.7 %
#   dom4      4.01     900 x 450     12.12         1.6 %
#
# Those are scaling estimates. This batch measures them. Production is the
# SMALLEST arm whose neck curve matches dom4 -- expected to be dom3.
#
# All three run the SATURATED control (h = 1.0000) so the comparison is on neck
# growth alone, with no shrinkage term to confound it. t_final = 2 h already
# covers their first three data points (t* to their first neck is ~0.4 h).
#
# Cost: ~1130 core-h for the set, about 8 % of the humidity sweep it protects.
#
# ANALYSIS
#   python postprocess/neck_width.py <run_dir> --axisym          # per run
#   python postprocess/plot_neck_convergence.py --runs <r1> <r2> <r3> \
#       --axisym --validation inputs/validation/molaro2019_fig11_T-20.csv
